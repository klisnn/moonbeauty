#  MoonBeauty

## 📖 Project Purpose

MoonBeauty is a modern cosmetic shop website created
to provide users with a simple and beautiful online
beauty shopping experience.

The website includes makeup, skincare and haircare
products.

The project was created as a frontend web development
project using HTML, CSS and JavaScript.

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- GitHub Pages

---

##  Website Structure

The website consists of five main pages:

###  Home

The main landing page of MoonBeauty.

###  About

Information about MoonBeauty, its story and values.

###  Services

Information about beauty-related services.

###  Shop

Product catalog with:

- Product cards
- Search
- Category filtering
- Product modal window

###  Contact

Contact information and a contact form
with JavaScript validation.

---

##  Main Features

- Responsive design
- Mobile, tablet and desktop layouts
- Dark / Light mode
- LocalStorage
- Product search
- Product category filtering
- Product modal window
- JavaScript form validation
- Accessible form labels
- Semantic HTML
- SEO-friendly page titles
- Meta descriptions
- Image alt attributes

---

##  How to Run

The website can be opened directly through
GitHub Pages.

To run the project locally:

1. Download or clone the repository.
2. Open `index.html` in a web browser.
